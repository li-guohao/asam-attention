% Abstract
\begin{abstract}
Sparse attention is usually motivated as a long-context efficiency technique, while continual learning is usually discussed through memory, replay, or task routing. We revisit both settings through a single object: an adaptive sparse routing operator that chooses a small support set, applies a capacity-aware assignment, and exposes the resulting routing geometry for audit. ASAM instantiates this view with differentiable sparse attention supports for long sequences and prototype-conditioned sparse routing for continual text classification. The current draft makes three deliberately conservative contributions: (i) a unified operator formulation that separates support selection, transport-style capacity projection, and sparse value aggregation; (ii) a mathematical account of when this operator reduces long-context work and when its prototype geometry yields interpretable continual-learning diagnostics; and (iii) an artifact-audited experimental protocol that separates artifact-backed benchmark evidence from LRA-style synthetic diagnostics and low-budget continual smoke tests. At this stage we do not claim official LRA leadership or a retention advantage over explicit task-ID routing. Instead, the paper reports the executable evidence currently available and uses negative results to define the next experimental gates.
\end{abstract}

\textbf{Keywords:} Sparse Attention, Adaptive Routing, Long-Context Modeling, Continual Learning, Artifact Auditing

% Motivation
\section{Motivation}
\label{sec:motivation}

Transformer architectures have revolutionized natural language processing, computer vision, and multimodal learning \citep{vaswani2017attention}. The core self-attention mechanism enables global information exchange but incurs $\mathcal{O}(n^2)$ time and memory complexity with respect to sequence length $n$. This quadratic bottleneck becomes prohibitive for long sequences exceeding a few thousand tokens.

Numerous approaches have been proposed to address this limitation. Sparse attention methods reduce complexity by limiting attention to specific patterns such as local windows \citep{beltagy2020longformer}, strided patterns \citep{child2019generating}, or random sampling \citep{zaheer2020big}. Kernel-based methods approximate attention using low-rank decompositions \citep{wang2020linformer} or random feature maps \citep{choromanski2020rethinking}. Memory-efficient implementations like Flash Attention \citep{dao2022flashattention} optimize I/O operations but maintain quadratic computation.

The same design pressure appears in continual learning. If every task uses the same dense representation, the model has no explicit mechanism for isolating, reusing, or auditing task-specific subspaces. If every task uses a manually supplied task identifier, the routing is strong but not autonomous. ASAM therefore treats sparse attention and continual task routing as two instances of one problem: learn a constrained routing distribution, expose its support, and regularize its geometry.

The central question is not whether sparsity alone is novel. Fixed windows, routing attention, kernel approximations, and post-hoc token selection are well established. The question is whether a single adaptive sparse routing operator can give two defensible benefits at once:
\begin{enumerate}
    \item \textbf{Long-context efficiency:} restrict each query to $k \ll n$ keys while preserving exact softmax attention on the selected support.
    \item \textbf{Continual routing geometry:} route examples through a small prototype support whose occupancy, capacity gap, and lifecycle transitions can be measured.
    \item \textbf{Auditability:} make every paper-facing number traceable to a manifest and dataset-provenance record.
\end{enumerate}

This draft positions ASAM as an early but executable framework rather than a completed empirical victory. Historical LRA-like plots in the repository are treated as synthetic diagnostics until official dataset provenance is attached. Current continual results are low-budget and include negative findings. This choice is intentional: the contribution should survive adversarial review even when the strongest baseline remains competitive.

Our contributions are:

\begin{itemize}
    \item We formulate ASAM as \textbf{adaptive sparse routing}: support selection followed by optional transport-style capacity projection and sparse aggregation.
    \item We show how the same operator specializes to long-context attention and to prototype-routed continual learning.
    \item We define artifact gates that prevent synthetic diagnostics, outdated manifests, or fallback data from being reported as official benchmark evidence.
    \item We report current audited evidence honestly, including a continual-learning smoke run where task-ID routing remains stronger than autonomous prototype routing.
\end{itemize}

% Related Work
\section{Related Work and Positioning}
\label{sec:related}

\subsection{Sparse Attention Patterns}

Sparse attention methods reduce the $\mathcal{O}(n^2)$ attention matrix to a sparse representation by limiting which tokens can attend to each other. Sparse Transformer \citep{child2019generating} uses strided patterns factorized across different heads. Longformer \citep{beltagy2020longformer} combines local sliding windows with global attention on pre-selected tokens. Big Bird \citep{zaheer2020big} adds random attention to local and global patterns, creating an expander graph structure.

These methods use \textit{fixed} patterns determined before training, which may not match the actual attention requirements of different inputs and tasks.

\subsection{Learnable Sparse Patterns}

Reformer \citep{kitaev2020reformer} uses Locality Sensitive Hashing (LSH) to bucket similar queries and keys, achieving $\mathcal{O}(n \log n)$ complexity. Routing Transformer \citep{roy2021efficient} employs k-means clustering on token embeddings to determine attention clusters.

Closer to our work, Tactic \citep{zhu2025tactic} uses clustering and distribution fitting for adaptive token selection during inference. However, Tactic operates post-training and is non-differentiable, whereas ASAM integrates adaptivity into the training process itself.

\subsection{Kernel-Based Approximations}

Performer \citep{choromanski2020rethinking} approximates softmax attention using orthogonal random features (FAVOR+), achieving linear complexity. Linformer \citep{wang2020linformer} projects keys and values to lower-dimensional spaces. These methods approximate full attention but sacrifice exact computation.

\subsection{Memory-Efficient Attention}

Flash Attention \citep{dao2022flashattention} reduces memory usage through tiling and kernel fusion while maintaining exact attention. While complementary to sparse attention, Flash Attention does not reduce computational complexity.

\subsection{Positioning of ASAM}

ASAM is positioned as a unifying operator rather than as a replacement for every sparse-attention family:
\begin{itemize}
    \item Fixed local or strided masks are valid ASAM supports, but learned scores can also choose supports from data.
    \item Post-hoc inference selection is complementary; ASAM focuses on training-time routing components where gradients flow through selected or relaxed routes.
    \item Kernel approximations compress the dense operator; ASAM keeps exact softmax attention on a selected support.
    \item Task-ID continual routing is a strong baseline; ASAM adds autonomous prototype occupancy and transport-gap diagnostics.
\end{itemize}

% Unified sparse routing
\section{Unified Sparse Routing}
\label{sec:method}

\subsection{Operator Formulation}

Let $\mathbf{X}\in\mathbb{R}^{n\times d}$ be a sequence or minibatch representation and let $\mathcal{U}$ denote a finite routing universe. For long-context attention, $\mathcal{U}$ is the set of key positions. For continual learning, $\mathcal{U}$ is the set of task or prototype slots. ASAM constructs a sparse routing operator in three steps.

\paragraph{Support scoring.}
Scores $S_\theta(\mathbf{X})\in\mathbb{R}^{n\times |\mathcal{U}|}$ are produced by a pattern scorer, prototype scorer, or hybrid of fixed and learned features. A support map
\begin{equation}
M_{iu}=\mathbb{1}\{u\in \mathrm{TopK}(S_{i:})\}
\end{equation}
keeps at most $k$ routes per item. Fixed local, strided, or random masks can be included by adding their support before or after top-$k$ selection.

\paragraph{Capacity projection.}
When route balance matters, the masked scores are projected toward a capacity vector $c$ with an entropy-regularized transport map:
\begin{equation}
R^\star = \arg\min_{R\ge 0}\ \langle R,-S\rangle + \varepsilon \sum_{i,u}R_{iu}(\log R_{iu}-1)
\quad \mathrm{s.t.}\quad
R\mathbf{1}=\mathbf{1},\ R^\top\mathbf{1}=c,\ R_{iu}=0\ \mathrm{if}\ M_{iu}=0 .
\label{eq:masked_ot}
\end{equation}
In practice this is approximated with masked Sinkhorn iterations or relaxed with a KL top-$k$ operator. If capacity is not needed, $R$ is simply the row-normalized masked softmax. The support constraint is important: a transport projection that ignores $M$ can reintroduce infeasible routes.

\paragraph{Sparse aggregation.}
Given values $V_u$, ASAM returns
\begin{equation}
\mathrm{ASAM}(\mathbf{X})_i=\sum_{u\in\mathcal{U}}R_{iu}V_u,
\quad \mathrm{supp}(R_{i:})\subseteq \{u:M_{iu}=1\}.
\end{equation}
This definition separates what is selected, how route mass is balanced, and how selected values are aggregated. It is the main abstraction used by both paper threads.

\subsection{Differentiability and Sparsity}

Hard support selection is piecewise constant. ASAM therefore uses it as an operator choice rather than pretending it is globally smooth. Gradients flow through the selected sparse softmax or through the relaxed transport map; support changes are handled by the scoring network across minibatches. For settings that require fully differentiable support discovery, the hard top-$k$ can be replaced by a temperature-controlled relaxation, but this draft treats that as an ablation rather than a universal assumption.

\paragraph{Complexity.}
If each row has at most $k$ active routes and values have width $d_v$, sparse aggregation costs $\mathcal{O}(nkd_v)$ after score construction. For attention, local and indexed supports avoid materializing an $n\times n$ score matrix. For learned global scores, the score-construction cost must also be counted; the paper therefore separates \emph{operator sparsity} from \emph{end-to-end runtime}.

\section{Long-Context Efficiency}
\label{sec:long_context}

Given queries, keys, and values $\mathbf{Q},\mathbf{K},\mathbf{V}$, dense attention computes:

\begin{equation}
\text{Attention}(\mathbf{Q}, \mathbf{K}, \mathbf{V}) =
\text{softmax}\left(\frac{\mathbf{Q}\mathbf{K}^T}{\sqrt{d_k}}\right)\mathbf{V}.
\end{equation}

ASAM replaces the dense key universe for each query $i$ with a selected support $\mathcal{S}(i)$. The sparse attention row is

\begin{equation}
\text{SparseAttn}(\mathbf{Q}, \mathbf{K}, \mathbf{V})_i
= \sum_{j \in \mathcal{S}(i)}
\mathrm{softmax}_{j\in \mathcal{S}(i)}
\left(\frac{\mathbf{q}_i\mathbf{k}_j^\top}{\sqrt{d_k}}\right)\mathbf{v}_j .
\end{equation}

The implemented support families include local windows, strided links, random links, clustered links, and hierarchical unions. A gate can mix a sparse path with a dense or SDPA path, but any claimed subquadratic runtime must refer to the true sparse path rather than a masked dense matrix multiplication.

\paragraph{Efficiency claim boundary.}
For a maximum support size $k$, the ideal sparse attention arithmetic is $\mathcal{O}(nkd_k)$ and the attention-state memory is $\mathcal{O}(nk)$, compared with $\mathcal{O}(n^2d_k)$ and $\mathcal{O}(n^2)$ for dense attention. This is a mathematical operator bound, not a hardware speedup claim. Hardware speedups require measured kernels, sequence-length sweeps, and memory traces. The current draft therefore treats repository microbenchmarks as diagnostics until their manifests are upgraded to the paper-facing provenance standard.

\section{Continual Routing Geometry}
\label{sec:continual_geometry}

In continual learning, $\mathcal{U}$ is a bank of prototype slots. Each example is routed to a sparse set of prototypes, and each prototype stores occupancy and task-conditioned statistics. The same masked transport operator in Eq.~\ref{eq:masked_ot} can be used to keep assignments near a target capacity while respecting the current feasible support.

\paragraph{Prototype stability.}
Let $R_t$ be the routing matrix at task stage $t$ and $P_t$ the prototype matrix. The current implementation exposes diagnostics such as
\begin{equation}
\Delta_{\mathrm{cap}}(t)=\left\|R_t^\top\mathbf{1}-c_t\right\|_1,
\quad
\Delta_{\mathrm{proto}}(t)=\min_{\Pi\in\mathcal{B}}\|P_t-\Pi P_{t-1}\|_F,
\end{equation}
where $\mathcal{B}$ is the Birkhoff polytope of doubly stochastic prototype matchings. These are not performance guarantees. They are geometry measurements that let us inspect whether a routing operator preserves capacity, reuses prototypes, or collapses to a small subset of slots.

\paragraph{Mathematical benefit.}
The transport term gives a controlled way to penalize route collapse. If $R$ is feasible for Eq.~\ref{eq:masked_ot}, then $R^\top\mathbf{1}=c$ by construction; with finite Sinkhorn iterations the observed capacity gap becomes a measurable approximation error. In a continual setting this matters because prototype occupancy is part of the model state. Balanced occupancy alone cannot prevent forgetting, but it creates an auditable route-allocation invariant that task-ID baselines do not expose.

\paragraph{Training objective.}
The continual variant uses a task loss plus regularizers for stability, overlap, diversity, balance, and transport:

\begin{equation}
\mathcal{L}=\mathcal{L}_{\mathrm{task}}
+\lambda_s\mathcal{L}_{\mathrm{stability}}
+\lambda_o\mathcal{L}_{\mathrm{overlap}}
+\lambda_b\mathcal{L}_{\mathrm{balance}}
+\lambda_d\mathcal{L}_{\mathrm{diversity}}
+\lambda_t\mathcal{L}_{\mathrm{transport}}.
\end{equation}

The current experiments should be read as operator diagnostics for these terms, not as proof that the full objective already dominates replay or task-conditioned baselines.

\section{Limitations}
\label{sec:limitations}

The current ASAM evidence is incomplete. First, the long-context efficiency result is currently an operator argument plus repository diagnostics, not yet a paper-facing speedup table. Second, the continual-learning evidence in the main branch is a small smoke run; stronger historical suites exist but fail the current strict provenance gate and are therefore not used for claims. Third, masked top-$k$ routing creates a support-discontinuity issue: gradients are reliable inside the selected support, but support changes are not globally smooth unless a relaxed top-$k$ estimator is used. Fourth, capacity-balanced routing can improve interpretability while still failing to improve task retention, as the current negative smoke result shows.

These limitations determine the next experimental priorities. If future runs show no advantage over task-ID routing or standard sparse baselines, ASAM should be framed as an auditable unified routing framework with negative early results, not as a performance-leading architecture.

\section{Conclusion}
\label{sec:conclusion}

ASAM reframes sparse attention and continual prototype routing as instances of a single adaptive sparse routing operator. The current mathematical contribution is the decomposition into support selection, support-feasible capacity projection, and sparse aggregation. The current empirical contribution is narrower: an artifact-audited pipeline that prevents unsupported benchmark-leadership claims and records negative continual-learning findings. The remaining work is to replace diagnostics with full paper-facing long-context and continual suites under the same provenance standard.

To assess whether the adaptive sparse-routing ideas behind ASAM can be extended to continual learning, we implemented a pilot continual-learning variant in the repository. This appendix intentionally presents the continual results as a conservative addendum rather than a replacement for the main long-sequence claims of the paper. The goal is to document the current executable continual-learning evidence, including both positive diagnostic signals and negative comparative findings.

\subsection{Setup}

We evaluate the continual extension on class-incremental Split AG News with 2 tasks of 2 classes each and a compact text classifier built from continual ASAM layers. The current paper-oriented run uses sequence length $64$, batch size $4$, $16$ training examples and $8$ validation examples per split, 1 layer with model width $32$, 2 heads, top-$k=2$ sparse pattern selection, AdamW with learning rate $3 \times 10^{-4}$, and 1 training epoch per task. Strategy-level and operator-level ablations are aggregated over 1 seed. This setting is deliberately modest and CPU-runnable, so it should be interpreted as a controlled pilot benchmark rather than a final large-scale continual-learning claim.

\subsection{Takeaway}

The current continual-learning results support a narrow but honest conclusion. The continual ASAM framework already provides executable transport-aware diagnostics, prototype lifecycle statistics, and operator-level ablations. However, under the present small-scale CPU configuration, these mechanisms do not yet translate into a retention advantage over an explicit task-conditioned baseline. The most defensible claim at this stage is therefore a framework-level one: continual sparse routing is measurable and partly interpretable, but stronger data scale, longer training, and richer ablations are still needed before claiming a clear empirical advantage.
