### 技术方案

**LRA 数据加载（`asam/datasets/lra_dataset.py`）：**

不依赖外部 LRA 包，自建轻量模块。五个任务：

- **ListOps**：生成长度 2000 的层级运算序列（`[MAX, MIN, MED, SM]` 运算符），token 数 ~20
- **Text**：IMDB 影评 byte-level 编码，截断/填充到 4096，256 个 byte token
- **Retrieval**：ACED 文档对，字符级编码，4096 长度，字符集 ~128
- **Image**：CIFAR-10 灰度图展平为 1024 像素序列，每像素 0-255
- **Pathfinder**：32×32 二值图像，判断两点是否连通，1024 序列长度

每个任务提供 `train_dataloader()` / `val_dataloader()` / `test_dataloader()`。

**训练管线（`experiments/run_lra_benchmark.py`）：**

```python
# 配置驱动
tasks = {
    "listops": {"seq_len": 2048, "num_classes": 10, "epochs": 5},
    "text":    {"seq_len": 4096, "num_classes": 2,  "epochs": 3},
    ...
}

# 模型配置：所有 baseline 统一 ~2M 参数
models = {
    "asam":       ASAMHFForSequenceClassification(ASAMHFConfig(dim=64, num_heads=2, ...)),
    "transformer": StandardTransformer(dim=64, num_heads=2, ...),
    "longformer":  LongformerBaseline(dim=64, num_heads=2, ...),
    ...
}
```

输出 `experiments/lra_results.json`：
```json
[
  {"task": "listops", "model": "asam",       "accuracy": 37.2, "time_ms": 42.1, "memory_mb": 98.7},
  {"task": "listops", "model": "transformer", "accuracy": 36.4, "time_ms": 178.2, "memory_mb": 450.2},
  ...
]
```

**论文图重生成：**

修改 `paper/generate_figures.py`：
- `generate_figure1`：从 `lra_results.json` 读 LRA 准确率数据

- `generate_figure4`：从消融实验 `ablation_results.json` 读数据

新增 `experiments/run_ablation.py`，测试 4 种配置：
1. Full ASAM（hierarchical + adaptive_gate）
2. - AdaptiveGate（仅 hierarchical pattern）
3. - Hierarchical（仅 local window）

### 验收标准

- `python experiments/run_lra_benchmark.py --task all` 全部跑通，无 OOM

**`ASAMHFForSequenceClassification(PreTrainedModel)`：**
```python
class ASAMHFForSequenceClassification(PreTrainedModel):
    config_class = ASAMHFConfig
    def __init__(self, config):
        self.asam = ASAMHFModel(config)
        self.classifier = nn.Linear(config.dim, config.num_labels)
    def forward(self, input_ids, attention_mask=None, labels=None):
        outputs = self.asam(input_ids, attention_mask)
        pooled = outputs.last_hidden_state.mean(dim=1)
        logits = self.classifier(pooled)
        ...
```

## 实施策略

### 并行性分析

四个子项目中有清晰的独立边界：

- **A（打包）** 独立于其他——修改的是项目根目录配置和 CI 文件
- **B（重构）** 与 C 有轻依赖——C 中 `modeling_asam.py` 从 `asam` 导入，需 B 先完成命名冲突解决
- **C（新功能）** 全部是新文件，不与 A/B 的文件修改冲突
- **D（基准测试）** 独立于其他——数据加载和训练管线是新增代码

**推荐的执行顺序：** A + B 先行（消除冲突 + 建立基础设施），然后 A+B+C+D 并行派发子代理。
